# Pore Terminology in Tissue Engineering & 3D Bioprinting

This repository serves as an open-access reference for the biological classification of interconnected pore sizes in biomaterials and tissue engineering scaffolds, moving beyond traditional IUPAC micro/meso/macro definitions.

## The Parvo-Medio-Magno Classification System

| Terminology | Size Range (Diameter, d) | Biological Context & Application |
| :--- | :--- | :--- |
| **Parvo-pores** | $d < 25\ \mu\text{m}$ | Cell attachment, focal adhesion restriction, capillary guidance. |
| **Medio-pores** | $25\ \mu\text{m} < d < 100\ \mu\text{m}$ | Dermal cell migration, initial cellular infiltration, extracellular matrix (ECM) deposition. |
| **Magno-pores** | $d > 100\ \mu\text{m}$ | Macrovascularization, nutrient diffusion channels, osteogenic niches for bone formation. |

## Why This Lexicon Matters
Traditional IUPAC terminology (micro, meso, macro) was designed for chemical gas adsorption, where a "macropore" is anything larger than 50 nanometers ($0.05\ \mu\text{m}$). In tissue engineering, cells are significantly larger, making the traditional scale impractical. The **Parvo-Medio-Magno** framework aligns terminology directly with cellular and tissue scale behavior.
