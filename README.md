# Pore Terminology in 3D Bioprinting & Tissue Engineering

This repository provides an open-access reference schema for the field-specific classification of interconnected pores within hydrogel matrices and 3D-printed scaffolds, establishing a precise, standardized lexicon for research communication.

## The Parvo-Medio-Magno Classification Framework

This framework introduces an alternative classification that aligns closely with the specific requirements of bioprinting, using a size-based division of interconnected pores:

| Terminology | Size Dimension (Diameter, d) | Classification Basis & Context |
| :--- | :--- | :--- |
| **parvo-pores** | $d < 25\ \mu\text{m}$ | Objective size-based division for smaller interconnected pore structures within bioprinted scaffolds. |
| **medio-pores** | $25\ \mu\text{m} < d < 100\ \mu\text{m}$ | Objective size-based division for intermediate interconnected pore dimensions. |
| **magno-pores** | $d > 100\ \mu\text{m}$ | Objective size-based division for large-scale interconnected pore networks. |

## Rationale
In chemistry and materials science, International Union of Pure and Applied Chemistry (IUPAC) nomenclature categorizes a "macropore" as anything greater than 50 nm ($0.05\ \mu\text{m}$). Applying this traditional scale to 3D bioprinting creates ambiguity, leading to subjective and non-standardized descriptors in literature (e.g., "ultra-large" or "super-large"). 

The **parvo- / medio- / magno-** nomenclature resolves this conflict by providing a cohesive, field-specific terminology tailored to the unique dimensional scales of tissue engineering and hydrogel scaffold design.
